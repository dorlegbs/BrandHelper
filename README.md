# 🚨 Brand Alert Bot

Sistema de monitoramento de crise de marca com alertas via Telegram.

## 🔧 Funcionalidades
- Monitoramento de menções em notícias
- Comparação entre dias
- Detecção de picos
- Envio automático de alerta

## 🚀 Deploy (Railway)

1. Suba este projeto no GitHub
2. Conecte ao Railway
3. Configure variáveis de ambiente:

- NEWS_API_KEY
- TELEGRAM_BOT_TOKEN
- CHAT_ID

4. Deploy automático 🚀
